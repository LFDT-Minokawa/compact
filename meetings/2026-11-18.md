# Agenda and Notes

- [x] **Improvements to reduce compile time**
  - Disclosure check (track-witness-data, the witness-protection pass that
    enforces disclose()): most of its cost is tracking paths, which are only
    used to explain a leak in an error message. I tried a first pass without
    paths that stops at the first leak, so the full pass runs only when there's
    an error to report. The full pass is also cheaper: path points are stored
    once and shared, and sorted path lists are merged instead of re-sorted.
  - Proving keys: one zkir process per circuit, in parallel, sized by
    processors, memory and container limits (--zk-jobs / COMPACT_ZK_JOBS),
    instead of a single compile-many that does the circuits one at a time.
  - Manifest: output files (mostly the keys) are hashed in parallel.
  - There's also room for optimization in midnight-zkir and midnight-zk.
  - fork: https://github.com/faculerena/compact/tree/compactf
  - contract link: https://github.com/midnightntwrk/passport
    - contract compiled: `account.compact`
  - pls put up a PR for the improvements in Compact and a proposal for improvements in midnight-zk and midnight-zkir
- [x] **Discussion on capsule runtime at some point on this platform**
  - MIP-25: https://github.com/midnightntwrk/midnight-improvement-proposals/blob/main/mips/mip-0025-capsule-runtime.md
